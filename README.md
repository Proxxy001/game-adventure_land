# Adventure Land Quiz

A colorful browser-based quiz game for kids that lets players choose a grade and subject, answer a short set of questions, and see instant feedback with explanations.

## Overview

Adventure Land is a playful educational web app built with HTML, CSS, and JavaScript. It is designed to make learning fun for elementary students by combining:

- grade-based quiz selection
- subject options like Maths, EVS, Hindi, and Science
- randomized question sets
- answer explanations after submission
- score tracking and replay flow

## Features

- Grade selection from 1st to 5th grade
- Subject-based gameplay
- 5-question quiz rounds per session
- Multiple-choice answers with instant selection feedback
- Final score summary with correct, wrong, and skipped counts
- Detailed answer explanations for each question
- Replay and navigation buttons to change grade or subject
- Space-themed, kid-friendly UI with animated background and sound effects

## Tech Stack

- CSS
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Proxxy001/game-adventure_land.git
```

2. Open the project folder.

3. Start a local web server or simply open `index.html` in a browser.

For example, with Python:

```bash
cd game-adventure_land
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Gameplay

1. Select a grade.
2. Choose a subject.
3. Answer the 5 questions.
4. Submit the quiz.
5. Review your results and learning explanations.

## Notes

This project is a front-end educational game and does not require any backend or database.
